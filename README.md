
# Customer Churn Forecasting for Telecom Providers

This project uses machine learning techniques to predict whether a telecom customer is likely to churn.

### Files
- `customer_churn_data.csv` — dataset  
- `CLEAN_vs_code_A_learning_model_on_customer_churn_forecasting_for_telecom_providers.ipynb` — final VS Code notebook  
- Project reports & presentation files

### Tools Used
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-Learn
